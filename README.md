# Cartão de Visitas Digital

Cartão de visitas feito com HTML, CSS e JavaScript, com alternância entre modo claro e escuro.

## Tecnologias
- HTML5
- CSS3 (variáveis CSS e media queries)
- JavaScript (DOM e localStorage)

## Estrutura
- `index.html`: estrutura da página
- `style.css`: estilos e temas
- `script.js`: troca de tema
- `Perfil_Profissional.jpeg`: foto de perfil
