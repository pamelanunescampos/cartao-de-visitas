# 💼 Cartão de Visitas Digital

## ✨ Funcionalidades

- 🌗 Alternância entre tema claro e escuro por botão.
- 💾 Preferência de tema salva no navegador (`localStorage`).
- 📱 Layout responsivo, adaptado a diferentes tamanhos de tela com media queries.
- 🎨 Temas definidos por variáveis CSS, o que facilita ajustar cores e identidade visual.

## 🛠 Tecnologias

- **HTML5**: estrutura semântica da página.
- **CSS3**: variáveis CSS, temas e media queries.
- **JavaScript**: manipulação do DOM e uso de `localStorage`.

## 📁 Estrutura do projeto

```
cartao-de-visitas/
├── index.html                # Estrutura da página
├── style.css                 # Estilos e temas
├── script.js                 # Troca de tema
├── Perfil_Profissional.jpeg  # Foto de perfil
├── README.md
└── LICENSE
```

## ▶️ Como usar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nada nem usar servidor.

## 🎨 Personalização

- **Cores e temas:** edite as variáveis CSS no início do `style.css`.
- **Foto de perfil:** substitua o arquivo `Perfil_Profissional.jpeg`, mantendo o mesmo nome ou ajustando o caminho no `index.html`.
- **Dados do cartão:** altere os textos e links diretamente no `index.html`.
